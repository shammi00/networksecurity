About This Dashboard

This dashboard provides real-time monitoring of your Network Security ML pipeline. Track model performance, manage training runs, and make predictions all from one place.

  • MLflow integration for experiment tracking
  • MongoDB Atlas for data management
  • Real-time model training and predictions
  • Automated data validation and transformation
System Information
Pipeline Type: Network Security Classification
Backend: FastAPI + MongoDB
ML Framework: Scikit-learn
Tracking: MLflow + DagsHub
Models: Random Forest, Gradient Boosting, AdaBoost
